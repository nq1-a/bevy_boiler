# Bevy boilerplate
A collection of things I use in almost every Bevy project that I don't want to rewrite

## Prerequisites
- Clang
- LLD
- Rust (2024 edition)

## Build instructions
To build and run a developer release, call `./run.sh` in your terminal. For any other edition, `cargo build` or `cargo run` with the `--profile` flag should suffice.

The first time you build, over 500 packages will need to be installed. This may take a few minutes, so please be patient.
